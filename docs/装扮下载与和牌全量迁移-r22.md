# 装扮资源下载与和牌迁移 R22

本轮目标：基础 APK 每类保留 2～4 款装扮，目标 200～300 MB；其他装扮以可校验资源包下载，支持资源页按类别批量管理及装扮选择页单件下载。先依据原版 Lua 移植全部可定位和牌特效。

实施顺序：

1. 审计固定配置、原生资源、Lua 特殊分支与包体依赖；建立逐项来源与状态。
2. 增加装扮资源目录、可续传下载／校验／安装／删除、运行加载与使用期保护；沿用角色资源的传输和离线局域网准备方式。
3. 将非基础装扮的重资源移出 Resources，保留轻量目录和图标；构建 Android／Windows 资源包。
4. 在资源页面加入角色／装扮资源入口；装扮选择页展示安装状态并支持单件下载，按类别提供批量下载。
5. 按 Lua 补齐和牌新旧根节点、动画牌、背景、延迟、声音、方向和销毁；逐项运行并录制实际预览。
6. 验证缺包、续传、坏包、删除、资源使用期、联机下载／替代、实际基础 APK 体积和最终包签名，记录真实通过范围再发布。

基础和牌暂定雷击／烈焰／Fate，立直暂定苍火／碎冰／火焰，其余类别约 3 款；以依赖闭包和实际构建体积决定，不用隐藏选项代替移出重资源。R21 自摸拍桌逻辑、手部 0.48、满贯以上横幅、镰刀 R13 等已确认行为保持。

初始磁盘余量：C 43.45 GiB、D 52.53 GiB。原生包复用既有固定版本缓存，只补必要包；D 低于 15 GiB 时停止新增资源获取。Unity 临时工程按需建立并清理，不复制整个角色源目录，不生成逐帧 PNG 缓存。

固定公开配置有 60 条和牌定义，其中一个标记已过期；原生清单有 64 个和牌资源键，含默认与尚未映射项。记录数不等于完成数，也不等于当前商店可购数量。所有缺失、未知组件和需要补充的 Shader／脚本行为分别记录，不用近似特效冒充原版。
