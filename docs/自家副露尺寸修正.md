# 自家副露尺寸修正（Unity 0.5.27）

只修改 `D:\MyWorkSpace\YunJianRiichi_Codex`。

0.5.26 在把自家副露移到右下角时，以手牌宽度的 63% 作为单张副露牌的投影宽度，并对副露根节点应用了初始缩放，造成显示尺寸偏小。这是布局调整引入的问题，与原 APK 牌素材无关。

本次取消该尺寸目标和初始缩小。先在原来的副露布局上测量单张牌的屏幕宽度，再以这个宽度进行贴底定位；移动产生的透视变化只用于补偿，保留之前的显示大小。右下角安全区、手牌避让、副露累积方向和原版牌资源继续使用既有实现。

实际 Unity Play 在 936×435、1280×720、1024×768 三种尺寸下检查 1～4 组副露：原布局单张宽度与调整后宽度之差均小于 0.001 像素，底边贴齐，副露与手牌分开且未超出安全区。936×435 下单张宽度为 41.63 像素。既有吃／杠动画及 1012 专项检查也通过。

预览为实际 Unity 渲染的合成局面，未进行安卓真机验证。
