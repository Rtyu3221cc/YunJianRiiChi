# 同类牌高亮原版对照

本次修正依据本地缓存的原版客户端脚本与用户提供的截图，结合 `dist/Majsoul_4.0.16_MC.apk` 提取的材质/网格；没有凭牌面截图重新估算高亮范围。

脚本：`build/reference/public/v0.11.252.w/code.js`，SHA-256 `f5a79786534cdb6f02d3f18d578227fef7dbf0cb515fa1461d7bffe7d3a82a9d`。缓存脚本是原版 Web 客户端，与 APK 的 Unity 适配管线分别核对。

| 原版逻辑 | 本项目适配 |
| --- | --- |
| `ViewPai.OnChoosedPai` 用 MJPai.Distance 判定同类，命中后 Vector4(0.615,0.827,0.976,1) | 赤五/普通五归一；颜色值直接采用原版 |
| `ViewPai.setMeshColor` 遍历 meshRender.sharedMaterials，设置每个材质颜色 | 同一个 renderer 参数覆盖 OriginalTileFace 和 OriginalTileBody；OriginalTileOutline 使用同一参数 |
| APK `mjp_face` 和 `mjp_mid` 保存 `_Tint` 等材质颜色属性 | 原纹理/UV/网格不变，整个模型的输出颜色乘以原版蓝色 |
| 选择结束恢复默认颜色 | 取消选择、状态刷新及新一轮统一恢复；手牌不附加同类特效 |

副露遮挡来自本项目使用独立前景手牌相机而仅预留右侧副露空间。解决方式是把各座位桌边副露/拔北的屏幕投影包围盒纳入左右避让；保留副露原网格、姿态和比例。原图中牌面与侧边都变蓝，本版实际 Unity 截图已核对；无同类黄色光圈。
