# 玩家信息页 R6：称号比例与页签字体

执行日期：2026-11-21，东京时间。本轮只处理用户两张截图指出的称号比例、成就栏字体、场别页签字体及绘制方式。

## 原因及修正

1. 称号 PNG 是 338×65（两张为 338×66），旧 TextureImporter 设置 `nPOTScale: 1` 会将其导入为 256×64。虽然代码用 ScaleToFit，依据的已经是变形后的纹理。14 张称号现在使用 None，禁用 mipmap，保留原始宽高、PNG 字节和原 GUID。大厅、称号簿等已有调用继续使用 ScaleToFit。
2. 原版页签是 75×75 的九宫格，左右边框分别为 20、35，预制体 Image 类型为 Sliced。旧实现将整图拉伸为 225×76，放大了边缘与倒角。本轮改为按原边框绘制九宫格，两个页签纹理也禁用 NPOT 重采样，导入后保持 75×75。
3. 成就标题原本错误使用 HYWenHei 数字字体，场别标签经 NText 映射到了大厅的另一份毛笔字体。现在成就标题和三个场别标签直接加载 APK 对应的 fengyucumaokai，字号 40；成就计数使用预制体引用的 haolong_0，字号 42。没有修改其他界面的公共字体映射。
4. 标签采用参考片中的「段位場／友人場／活動場」原字形。原字体不含简体「场」，直接保留简体会出现空字；原版繁体字形已在 Unity 中逐字检查。数据键 ranked / friend / competition 不变。

原版依据：4.0.16 APK 的 UI_PlayerInfo，标题节点 108、计数节点 111、页签节点 120–130。haolong_0 直接从节点引用的 Font 对象提取，字体数据 SHA-256 为 `5d6561c9b4d77cbca4387ddf56650a4d1c900f385d3e34c72fc9a80f1dc60256`；毛楷文件与工程原字体逐字节相同，未使用替代字体。
