# 角色资源实验：八木唯（历史实验记录）

后续完整发布已经扩展为女性TOP10＋汪次郎，并接入Unity 0.6.6，见[0.6.6交接](handoff-unity-0.6.6.md)。以下保留初版实验过程与当时边界。

用户授权范围：启动资源选择、设置资源管理、宿舍未下载遮罩、可用角色筛选、删除清理；使用八木唯验证完整资源下载与联机缺包处理。一姬、二阶堂美树始终内置且不可删除。推荐集合为女性TOP10＋汪次郎，其他男榜以后补充。当前先做实验和效果验证，不自动发布新APK或推送整套代码。

设计：统一角色目录与安装状态；重型资源采用Android AssetBundle，清单给出版本/大小/SHA256/兼容版本。现有未来、寺崎千穗理迁移为可删除资源包，保留其源素材；八木唯包含全部9套皮肤、原始动态骨骼、语音与表情。GitHub只发布实验资源附件和目录供实际下载验证，不改主程序Release。

初次进入大厅提供全部可用、推荐集合、暂不下载。未发布包明确不可下载。设置增加资源页，支持列表、批量、取消、删除；内置资源受保护。角色包安装完成后才可出战、入随机池和标星，删除后清理当前选择、随机池与星标。游戏中和正在共享的包引用锁定。

联机：开局准备先冻结本场角色，所有真人对同一准备版本确认资源可用或接受一姬显示替代，房主据此正式开局。取消、失败和退出可解除等待；重连不重新抽取，局内缺包不阻塞牌局。分享服务只提供清单认可的角色包，支持范围请求和房主中转，不占用房间消息线程。

验证应包含实际Unity下载/校验/安装/展示/删除、断点与损坏包、基础包保护、批量筛选；Node房间准备协议测试；真实HTTP局域网传输与中转。编辑器/回环验证不能宣称已通过安卓多手机热点与安装测试。

## 完成情况（2026-10-20）

八木唯资源包已经实际构建和发布，含9套服饰、两套动态（悸动之夏、云踪侠影）、174段语音、23张表情。云踪侠影有两个独立骨骼层，本轮增加合成渲染。Windows编辑器包22,862,991字节，Android包22,864,339字节；包内资源地址经过检查。未来与寺崎千穗理也制作成可管理包，源素材保留在 `unity/Assets/CharacterPacks/Source`。共享字体、界面、运行时保留在基础客户端，两个基础角色不迁出。

启动提示、设置资源页、全部/推荐/自选下载、列表与全部删除确认、宿舍黑色遮罩、下载大小及进度、出战可用性过滤和删除后的偏好清理均已实现。推荐集合是女性TOP10＋汪次郎。目录覆盖122名角色，但本轮只发布三个可选角色包，其余明确暂不可下载。内置目录和可下载清单只列出已发布包中真正包含的服饰。

资源包通过独立的[实验Release](https://github.com/Rtyu3221cc/YunJianRiiChi/releases/tag/character-resources-experiment-1)分发。目录应使用 `catalog-windows-r2.json` / `catalog-android-r2.json`，初版目录保留作历史记录。r2纠正了寺崎千穗理目录多列出一套未取得服饰的问题，所有bundle字节和哈希保持不变。本轮没有推送主程序源码或发布新APK。

## 核心入口

- `CharacterPackService.cs`：受保护角色、串行下载队列、续传、取消、大小/SHA256校验、安装收据、文件删除与引用保护；持久路径为 `character-packs-v1/<role>/<sha>.bundle`，收据在验证和加载完成后写入。
- `CharacterResourceUi.cs`、`CharacterResourceOverlay.cs`：首次提示、下载确认与资源管理；复用原包面板、按钮和字体，全屏遮罩覆盖宽屏边缘。
- `CharacterRoster.cs`、`CharacterVoices.cs`、`CharacterIllustration.cs`：统一读取资源包；未安装角色使用轻量头像，远端缺包时本机回退一姬；普通角色目录与本机安装状态分离。
- `ResourceRoomCoordinator.cs`：冻结准备版本、各设备资源确认、取消、一姬替代、预载、正式开局及引用锁；JSON null准备对象会先规范化，避免空对象误触发等待。
- `CharacterPackShareServer.cs`：独立流式HTTP服务、受限文件能力票据、范围请求、房主中转；不使用房间消息线程传输大文件。
- `engine.js`：角色目录、资源准备快照、状态确认、成员变动失效、旧确认拒绝、超时取消、房主恢复后重确认并保留随机结果。原有不启用资源协议的测试/客户端维持旧流程。
- `RoomService.java` / `desktop.cjs`：由服务端写入真实来源IP，避免客户端伪造任意中转地址；房间JSON请求上限64KiB。

## 实验边界

局域网传输验证为同一机器上的真实HTTP源和中转服务，房间为真实Node HTTP服务，其他玩家由测试请求模拟；UI操作通过编辑器验证入口驱动。**没有完成Android真机安装、触摸、多手机热点、后台传输或低内存设备验证。** Android资源包已构建并检查资源地址，但不能将这些检查说成手机端验证。

本轮没有批量制作其他角色包，也没有实现运行中发现全新资源目录的自动热更新；目前实验版使用内置可信目录和固定版本GitHub附件。后续扩充时需发布兼容的新目录，并继续核对版本、皮肤内容和客户端能力。当前队列以角色包为单位串行处理，批量取消会取消本轮排队任务。默认首次提示的选择会记住，之后从设置资源页进入。

## 复现

`prepare-character-pack-experiment.py`提取/整理源素材；`BuildCharacterPacks.Run`分别构建Windows、Android包；`publish-character-pack-experiment.py finalize-r2`生成目录，`publish-r2`仅追加目录附件。`CharacterPackExperiment.Run`在独立持久目录运行实际Unity实验，需要 `desktop.cjs` 使用实验房主配置监听8765。完整单元检查仍使用 `verify-unity.ps1 -Mode Validate`。
