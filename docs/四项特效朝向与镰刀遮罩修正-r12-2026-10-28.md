# 四项特效修正 R12

根据上一轮预览反馈，修正 K.O.、猫过留痕、问心之镰和滚雪球效应。本轮仍不生成 APK。

视频来自实际运行的 Unity 牌桌、手部与特效组件；本轮四款以 60 帧录制，原有其他条目保留原预览帧率。录制 fixture、牌河位置和相机构图与原版预览不同，不将专项检查通过等同于逐像素一致。

## 修正内容

1. K.O. 原生字牌朝向与本游戏观察方向相反。旋转整个效果的世界朝向，使字样从左到右正常显示，保留原贴图和粒子动画。
2. 猫过留痕和雪球的预制体已有表面旋转，上一轮却额外套用了牌模型网格转换。单独记录它们的挂载坐标，恢复沿横放立直牌长边的猫爪、滚入、拖尾与扩散方向。
3. 问心之镰使用独立挂载朝向，恢复镰柄横向挥动及刀刃面向。保留四个原生变体及编译动画采样。
4. 从本次客户端原始 shader bundle 提取的可读 GLES 程序确认：遮罩采样的是 Alpha 通道，UV 旋转使用 `anim.z * _Time.y + anim.w`（弧度），主色 Alpha 不额外乘进源 Alpha。补齐对应运算和遮罩贴图寻址设置，修正镰刃出现与消隐。证据保存在 `source/r12/`。

坐标修正保存在四个动作包装 JSON 的 `nativeWorldEuler`／`nativeTileEuler`，不改源预制体层级和粒子旋转曲线。其余装扮仍使用原挂载默认值。重新注册脚本也保留这四项设置。原生 FizzFX 材质由 shader 统一处理 UV 时间，不再叠加第二次材质偏移。
