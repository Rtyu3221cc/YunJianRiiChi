# 0.5.38 副露贴靠

在已认可的0.5.37尺寸体系上，去掉副露组内额外留白及组间预留间隙，按实际模型与描边的可见边缘贴靠。横置牌使用旋转后的可见长度占位，暗杠也以半张牌的中心偏移对齐组边界；加杠仍叠在被碰牌上。

桌面牌世界宽度继续为0.35，自家操作手牌大小、透视相机及区域对齐方式沿用0.5.37。牌组总跨度缩短后，手牌按现有避让逻辑释放出来的空间排布。
