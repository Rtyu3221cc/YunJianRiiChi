# 和牌与立直特效音效核对

更新于 2026-11-11 22:54（东京时间）。

核对当前 63 款和牌、57 款立直特效。修正前有 4 款和牌和 46 款立直缺少音效绑定，其中包括「和牌-神火坠霄」、默认雷击、「和牌-天罚！」和「和牌-灵感大暴走」。现已补入 50 份官方 MP3（2,303,644 字节）及对应 Unity .meta，并修复 catalog 的 cue。

「立直-苍火」的原版 view.audio_id 为 0。其余 119 项各有音效绑定与可解码文件。

## 缺漏原因与修复

R30 注册脚本只在音效文件已经存在于本机 Audio 目录时设置 cue，新增资源阶段没有取得这些音档，因此新特效保留了图形、播放配置和下载包，音效绑定为空。默认雷击另有一处旧遗漏，原版 DesktopMgr 的默认和牌 audio_id 为 213，对应 ui/mj/main/audio/hupai。

本轮用原版 item_definition/view 与 audio/audio 表核对 ID 和原始音效路径，从官方 DXT 音频目录取得缺漏的 MP3。新增声音放在 Assets/Resources/Majsoul/Audio，随下一次 APK 内置。完整对照、官方下载 URL、文件长度与 SHA-256 见 [核对数据](effect-audio-audit-2026-11-11.json)。

## 验证

- 独立解码器完整读取 119 份音频，全部具有有效、有限且非零的音频采样。神火坠霄音档为 6.1 秒、双声道，峰值约 0.7086。解码报告在 build/effect-audio-r33/decode-report.json。
- Node 默认隔离测试命令 node --test tests/*.test.cjs，199/199 通过，包含新增的三项音效回归检查。
- Python 角色输入测试 8/8 通过。
- Android、Windows 均验证每个 cue 可由内置资源或该特效资源包的依赖加载，50 份新资源的 .meta GUID 有效且互不重复。
- Unity 批次验证首次因沙箱阻止 Package Manager IPC 失败；沙箱外重试后，Unity 返回授权错误 198，提示 com.unity.editor.headless 缺失，验证脚本未执行。游戏内播放和 Android 真机验证待完成。
- 本轮只更新本机工程。当前手机试装版 0.6.32 需要重新构建 APK 才能包含这些修正。

Unity 验证入口已准备在暂存工程 Assets/Editor/EffectAudioR33Review.cs，方法为 YunJian.Riichi.Editor.EffectAudioR33Review.Run。授权恢复后可用原来的暂存工程重跑，输出路径通过 YUNJIAN_EFFECT_AUDIO_REPORT 指定。
