# 鸣牌指示 R8：牌字可读性

本轮只处理鸣牌指示遮盖牌面的问题，输出效果视频，不生成 APK、不提交或上传 GitHub。

## 调整

R7 的覆盖材质解决了邻牌切掉特效的问题，也使部分中心发光／暗色层直接盖住了目标牌字。R8 保留既有深度策略，在鸣牌实例材质中增加柔和的牌面减淡：根据实际碰撞体顶面和观察射线确定当前像素是否叠在牌面上，中央减淡，边缘平滑过渡，外围继续显示。该区域随牌的旋转、缩放和四个观察座位变化，没有新增游戏摄像机或运行时离屏贴图。

各款叠加强度分别调整，避免只将整个特效缩小后挤在牌字上。

| 指示 | 整体强度系数 | 牌面中央叠加系数 |
| --- | ---: | ---: |
| 雷驰电掣 | 0.82 | 0.16 |
| 咕噜咕噜 | 0.90 | 0.28 |
| 众星捧月 | 0.72 | 0.12 |
| 樱瓣试装 | 0.75 | 0.10 |
| 蝙蝠试装 | 0.78 | 0.055 |

这些是各粒子层的混合系数，最终画面仍与重叠层数和原材质有关，不能解读为最终屏幕固定透明度。

普通引导保持原材质深度与图案。其他鸣牌指示仍使用覆盖深度，不恢复邻牌遮挡。参数只由 `WardrobeResponseIndicator` 写入独立材质，和牌、立直等共享着色器的其他实例默认不开启牌面减淡。

## 录制和检查

六款指示分别从四个座位观察同一张牌河目标。编辑器可观察出牌者自身视角，实战仍遵守原有合法响应条件。

每种样式、每个方向检查 0.15、0.5 和 1.1 秒三个时刻：同一帧内分别渲染旧效果、关闭粒子渲染器的牌面基准、新效果。只关闭 Renderer，避免禁用 GameObject 重置粒子后误判为“没有遮牌”。检查实际牌字像素相对基准的颜色偏移，以及外围仍可见的效果像素；普通引导作为对照。数值只是采样时刻的可读性检查，另以完整动画视频核对形状与过渡。

入口为 `WardrobeR8Review.RunStudy`、`WardrobeR8Review.RunFull` 和 `scripts/package-wardrobe-r8.py`。最终页面位于 `dist/previews/2026-10-27-wardrobe-r8/`，包含同步的上轮／本轮视频、优化后的全桌与局部四视角，以及手机离线单文件。对照左侧采用 R7 实际录制帧，右侧采用 R8 实际录制帧；同帧采样截图另外用于隔离本次材质调整。
