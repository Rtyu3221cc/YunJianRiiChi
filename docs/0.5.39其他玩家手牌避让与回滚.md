# 0.5.39：其他玩家手牌避让副露

0.5.38 将副露按可见牌边缘贴靠后，其他玩家的站立手牌仍使用固定中心，四组副露等局面会与手牌重叠。0.5.39 根据副露模型与描边的实际边界，沿每名玩家的牌列平移手牌；按用户确认的第二版预览保留更大的间距。无副露时手牌保持原中心。

站立手牌、和牌摊牌和荒牌流局摊牌共用避让规则。自摸局面为自摸牌预留位置，自摸牌随摊牌平移，并继续继承落地目标的尺寸。镜头调整及已有手牌避让结束后重新对齐，防止副露最终位置改变后再次重叠；轮询重建和动画交接也使用最终位置。

牌的统一世界尺寸、相机透视、自家操作手牌大小、副露大小与贴靠方式保持。该修正只调整其他玩家手牌沿牌列的位置。

[17张实际渲染截图](../dist/unity-0.5.39-screenshots.html)包含三／四人桌的同场景前后对照，以及站立手牌、自摸摊牌、流局摊牌／扣牌。截图来自 Unity 合成测试局面，并非安卓真机截图。
