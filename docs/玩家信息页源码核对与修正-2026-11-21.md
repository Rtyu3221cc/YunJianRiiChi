# 玩家信息页源码核对与修正

执行日期为 2026-11-21，东京时间。用户已确认拥有界面和素材的复制使用授权。

本轮检查本机雀魂 4.0.16 APK 中的 UI Lua 和预制体，并据此修正玩家页。R2 的重新设计和 R3 对共用称号背景的使用存在偏差。

## 查到的原版实现

| 部分 | 本机证据 | 原版行为及本轮处理 |
| --- | --- | --- |
| 主界面 | build/apk-rank-title-study/decrypted/ui_playerinfo.lua，UI_PlayerInfo、PageMJStatistics | 主界面与三麻、四麻的统计页分开，按场别切换统计。主预制体有 792 个节点，本轮按其 1920×1080 画布读取边框、立绘、称号、名字、段位、竖排模式、内页签与滚动容器的位置。 |
| 称号 | 同目录 ui_playertitle.lua，UI_PlayerTitle.SetId | 通过称号 ID 查询 item_definition/title 的 icon，异步加载整张称号图片。当前实现也用图片资源绘制，原版图中的文字与装饰一起保留。 |
| 称号簿 | 同目录 ui_titlebook.lua，UI_TitleBook.OnShow、SetItemValue | 显示已拥有称号，按 priority 排序，用原图和使用中标记，行高 99.2。此前自绘的徽章与佩戴按钮已替换。 |
| 获得称号背景 | 同目录 ui_gettitle.lua，UI_GetTitle；ui_gettitle.prefab | title_get_bg 是获得称号弹窗的背景。R3 把它用于单个称号的做法错误，本轮移除。title_spilit 继续用于称号簿分隔线。 |
| 高光图标 | UI_PlayerInfo.PageMJStatistics.InitHighLight、RefreshHighLight；build/player-info-source-r4/decrypted/badge_group.lua | 配置中按徽章组指定图片，只有非零记录显示。原始图标在 APK 的 extendres/badge 图集中，已读取并替换几何手绘图标。 |
| 最近走势 | UI_PlayerInfo.PageMJStatistics.InitTrend、RefreshTrend | 原版切换 10、20、50 战，并在上下界禁用加减。当前界面已对应这三档，保留 R2 修复后的线段连接。 |
| 立绘框 | ui_playerinfo.prefab 的 Root/illust/frame | 是 border 为 50 的九宫格图片。直接拉伸会把边框遮到人物上，本轮按九宫格绘制。 |

## 新资源及代码

- unity/Assets/Scripts/LobbyController.PlayerInfo.cs 按原版预制体重新布局，加载真实图片，接入统计区滚动并将 ID 放回右下角。
- unity/Assets/Scripts/PlayerTitles.cs 增加 sourceId、resource、priority，沿用既有本地称号 ID，图片显示也供大厅、房间与开场的现有调用使用。
- unity/Assets/Resources/Majsoul/Profile/Native 来自本机 APK 的原始精灵，native-art.json 记录其路径、PathID、边框和摘要。
- 图集中的紧凑裁切按 m_Rect 和 textureRectOffset 恢复透明画布，避免三麻、四麻页签和徽章被错误放大。空记录时保留高光标题。
- unity/Assets/Resources/Majsoul/Profile/TitleIcons 来自本机已保存的官方版本索引对应的资源地址。读取项目既有图片编码方式后验证 PNG，称号图片没有重新绘制。

## 数据边界与兼容

称号获得方式采用保留现有离线解锁条件的方案。原有存档 ID 和解锁条件保留，对应称号名称与图片改用原版配置。映射如下。

| queshi | 原初之火 | 600002 |
| quejie | 萤火之光 | 600003 |

参考录像中的六个契约者、启迪者称号用于隔离预览。它们的 condition 为 manual，普通存档不会因测试自动获得。演示战绩、人物和录像中的账号数据不同。

本轮聚焦显示层。现有风格统计仍使用离线版的累计统计，原版 MakeStyleData 使用最近 20 次和牌、最近若干手与最近 10 次和牌的统计，这些算法尚有差异。此前首版范围排除了成就系统，因此原版成就条的数据与入口尚未接入。高光仍映射现有离线计数，未接入原版成就服务。

## 核验和交付

Unity 录制检查 57 项通过，覆盖称号佩戴、昵称、三麻、四麻、终局记录与 20:9 截图。成片全帧解码，检查 25 个走势点和 24 条连接。新录像和对照图位于 dist/previews/2026-11-21-player-info-r4/。

共享规则要求的回归命令本轮已运行：`node --test --test-isolation=none tests/*.test.cjs` 209 项通过；Codex Python 运行时以 `-B -m unittest discover -s tests -p test_character_inputs.py` 运行，8 项通过。Unity 日志另有隔离预览目录的 WardrobePackService 校验路径异常和编辑器 SearchDatabase 索引异常；它们不在玩家页调用链中，录制和 57 项断言完成。本轮没有修改这两个模块。

对照视频按页面状态对齐，保留各段原速。左侧是用户原录像，右侧为本轮 Unity 编辑器实录。它们的页面切换时刻与演示数据不同，视频包含切换到对应页面的剪辑。

暂存工程录制后恢复，新代码需在下次出包前同步。当前 0.6.39 APK 仍包含旧 R1 页面。本轮未进行 Android 真机验证。
