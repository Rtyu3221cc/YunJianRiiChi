## 对照依据

本机 4.0.16 APK 的 UI_PlayerInfo、UI_TitleBook、UI_ChangeName 预制体，及已提取的 UI Lua。除 RectTransform 外，本轮同时读取了 GameObject 的 active 状态和布局组件：VerticalLayoutGroup 的宽度分配、210/220 像素区块高度，HorizontalLayoutGroup 的 14 像素徽章间隔，以及文字 ContentSizeFitter 的尺寸。

只按原始未排版的坐标计算会让节点重叠，因此先应用布局，再计算世界坐标。示例：风格标题文字在画布 (711,593.1)，雷达在 (935,624.9)，首个高光图标在 (1215,655.9)，最近走势首个 50 战圆点中心在 (775.1,885.5)。原版 bg_player_rank 的 bgp 节点默认不激活，本轮不显示该底图。

资料和运行证据位于 build/player-info-source-r5/review/，包括布局、预制体、资源索引、录制检查和视频解码报告。原 APK 文件本身未复制到预览目录。

- 两支视频全帧解码，并检查 25 个走势圆点、24 条线段。逐组件图由已解码视频和 Unity 截图裁切，没有手工绘制替代截图。

## 保留的数据边界

成就条恢复原图与位置，但三个计数为不可用占位“—”，不伪造在线账号成绩；入口说明当前成就统计不可用。称号解锁和既有本地 ID 沿用 R4；风格统计仍使用离线累计记录；精选和牌图标说明本地自动展示最佳和牌，不提供服务器的手牌收藏选择。改名保持本地免费规则，未加入原版服务器货币与冷却。

“活动场”使用原版显示名称，存档键仍为 competition，兼容此前“比赛场”记录。高光沿用本地六种计数；原版常规徽章间隔适用于五个以内，六种同时出现时压缩间隔以防越界。角色、昵称、字形地区和演示战绩与原片不同，不能把全画面像素差异直接作为组件布局误差。

本轮没有构建或发布 APK，也没有 Android 真机测试。录制后恢复暂存 Unity 工程；主工程保留最终源码、原图和 meta。下一次出包前应同步本页脚本和 Profile 资源。
