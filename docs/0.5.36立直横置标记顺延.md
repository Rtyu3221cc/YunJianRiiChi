# 0.5.36 立直横置标记顺延

立直宣言牌被吃、碰或明杠拿走后，该玩家下一张打到牌河的牌也横置。如果这张横置牌又被拿走，标记继续顺延，直到有一张横置牌留在牌河；随后弃牌恢复通常方向。

根据原始公开弃牌记录中的“立直宣言”和“被副露拿走”标记计算显示方向。没有修改真实立直宣言字段，因此不重复喊立直、扣1000分或放置立直棒；规则操作、存档格式及牌张统计沿用原逻辑。Unity和网页牌桌都采用相同计算方式，旧存档和轮询重建也能推导正确方向。

验证包括真实引擎中的吃、碰、明杠场景及一整圈返回立直者的后续出牌；确认只扣一次立直棒、普通弃牌事件仍是普通事件。另检查连续拿走横置牌、跨行排列、历史记录不被修改，以及实际Unity落牌模型／手部动画与横置目标一致。
