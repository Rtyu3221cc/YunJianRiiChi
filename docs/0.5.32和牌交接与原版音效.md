# 0.5.32 和牌交接与原版音效

针对四项反馈修正：

1. 荣和／自摸时，摊开的3D手牌初始隐藏；自家站立手牌淡出完成并停用后，才启用倒牌动画。轮询重建仍保持该顺序；其他玩家和牌时，自己的未和牌手牌保留。
2. 和牌横幅开始时播放 APK 原版 `myassets/ui/mj/main/audio/cutin.mp3`，源时长约1.515秒。
3. 开局名牌使用 APK 原版 `myassets/ui/mj/main/audio/winlose.mp3`，源时长约2.142秒；与胜负字出现同步，并在播放条件就绪后才标记已触发。每次新整局只播放一次，普通轮询不重播。该资源原本已存在，此次重新从APK导出核验相同字节，并补充来源记录。
4. 自家副露向下移动7个屏幕像素，保留0.5.31放大后的尺寸及手牌原大小。

音频直接从用户提供的 `Majsoul_4.0.16_MC.apk` AudioClip 导出为 PCM WAV，未使用下载替代音效或合成音效。原路径、bundle、pathID、导出 SHA-256 和时长见 `Audio/provenance.json`；脚本为 `scripts/import-presentation-audio.py`。
