# 原版提示与结算音效（Unity 0.5.22）

本次对照用户截图、《荒牌流局.mp4》和《荣牌特效.mp4》，保留一姬立绘。以原版皮肤配置、声音表、角色声音表和 UI 调用顺序核对资源，避免按文件名猜测。

## 提示框和张数

听牌与吃牌组合使用 `pop_bound` 金边花纹框配合 `pop_bg` 深蓝底图，按原始九宫格边距缩放；听牌下方的蓝色张数底牌使用 `bg_3`。吃牌组合没有张数标签。牌和张数分别置于框内，流局待牌整体在框的中心。荒牌流局标题用原图可见像素范围居中，并将牌桌世界中心投影到 UI 坐标，避免宽屏留边和图片透明边缘造成偏右。

未见张数 = 四张实体牌 − 自己手中同种牌 − 未被鸣走的公开弃牌 − 公开副露（含暗杠声明的四张同种牌）− 已拔北 − 已亮出的宝牌指示牌。抢杠/抢北决策阶段已公开宣告的牌也计入，宣告者自己的牌仍只计一次。红五与普通五合并；被鸣走的弃牌仅在副露中计一次。预选弃牌只是从自己的手里移到公开牌区，未见张数不会凭空增加。对手暗牌、牌山和未公开的里宝牌不参与计算；三麻不存在的二至八万为零。

## 原版语音与声音顺序

解析原始 `fan.fan`、`voice.sound` 的一姬记录，以及 `audio.audio`。使用 82 条原版一姬役种/结果语音，覆盖宝牌一至十三、单双风牌和一至六倍役满。结算先按 `show_index` 排役种，每一条的出现与语音同时发生；下一条至少等前一条的原始时长和实际 AudioClip 长度，避免截断。随后依次显示番符、点数和满贯等级。

## 录像对应火龙卷

原始 `item_definition.view` 将皮肤 **305034** 映射到 `scene/ron_huolongjuan.lh`，声音编号 **305034** 映射到 `audio/audio_mj/ron_huolongjuan.mp3`。此前普通火焰及程序绘制的旋风形态不符；现在使用火龙卷的九个发射器、真实 `yuanhuan-Tube001` 环形网格和原版柱面贴图网格、碎石贴图、大小/透明曲线、旋转速度和序列帧。坐标的 Z 轴反射并采用与麻将模型相同的单位转换。

原版音频与《荣牌特效.mp4》降采样音轨的归一化波形相关度 **0.991037**，在录像音轨约 **1.624 秒**处匹配，确认音效资源身份。该偏移用于辨认录音，不作为玩家每次播放的固定等待时间；客户端由胡牌特效启动触发音效，特效完毕后才开始报役。

## 来源与验证范围

框、张数底牌、桌面和结算音效、能在目录中匹配到的特效贴图，从用户提供的雀魂 4.0.16 APK 导出。本地 APK 音频目录未包含一姬角色语音，也缺少火龙卷独立场景；使用雀魂官方固定版本资源补充，并全部打包离线使用。`pop_bg` 底图同样由官方原始 atlas 补充。来源、对象编号和 SHA-256 记录在 `SettlementVoice/provenance.json`、`SettlementVoice/manifest.json`、`Audio/provenance.json` 与 `Indicators/source.json`。游戏运行时不联网下载这些素材。

自动验证覆盖规则/公开协议 78 项，实际 Unity 的非本回合选牌、跨轮询/摸牌绑定、四种显示比例的提示框和流局居中、82 条语音加载、报役顺序、所有满贯鼓声等级、音效去重与跳过，以及既有拔北、手部动作、听牌长按、振听、三/四人和牌与结算回归。预览使用合成公开局面；安卓真机触摸、扬声器听感和热点联机不属于这次自动验证。
