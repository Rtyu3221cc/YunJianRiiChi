# 0.5.35 逐项修正与验证

1. 听牌指示器宽高从36改为54，均放大50%；长按允许少量手指漂移。未选牌但存在打牌后听牌的情况，现在展示可听牌的舍牌及对应听牌，避免按钮有响应但没有内容。
2. 其他玩家和牌后保留站立手牌，直到推倒行启用的同一帧再隐藏。轮询重建保留该衔接，避免等待横幅期间空一阵子。
3. 使用APK的“胜负”文字与花瓣；将文字独立绘制，按视频由大缩小，避免原粒子字层在透明阶段已完成缩小而看不到该过程。
4. 所有AI操作统一等待随机500～800ms，包括打牌、荣和、自摸、吃碰杠、拔北、跳过。新状态使旧思考计划失效；每个新决策重新等待。开局／新一局整理手牌先等待展示。主机以50ms轮询调度，实际执行还会有少量调度／计算耗时。
5. 荣和／自摸改用APK `UI_HuleShow` 原贴图、玩家位置、尺寸与3到1的缩放提示，移除该提示阶段的角落角色弹出；之后的原版横幅与一姬立绘继续保留。对当前画布做等比适配，避免对家提示文字被裁切。
6. 每个玩家的北牌按缩放后的模型宽度紧邻摆放，保留此前的尺寸及朝向规则。
7. 移除对局中的等待响应文字；结算确认信息保留。
8. 流局自家手牌采用与自家和牌摊牌相同的0.35宽度、0.37间距与推倒曲线，增加与牌河的距离。听牌摊开的桌边距离为4.05，未听牌扣下为4.34；有副露时仍从左侧手牌位置开始排布。旋转过程的抬升高度按实际牌长计算。
9. 新增APK原版 All Last 贴图和UI入场参数。在三麻／四麻、东风／半庄的计划最后一局及延长局开始时提示；每个新手牌包括连庄只出现一次，轮询不重复，较晚重连不补播。已知结算到下一局的转换不依赖两部手机的时钟完全相同。
10. [尺寸计算分析](牌桌尺寸计算分析-0.5.35.md)，本项只分析，不调整全局尺寸。
11. 所有排队待播放的拔北事件在收包时就隐藏对应北牌；第一次、第二次搬运及落地分别处理，已有北牌不会被后一张的动画隐藏。轮询不会提前显示待放置的牌。

素材来源见 `Presentation0535/source.json`，包含用户提供APK的bundle、pathID及导出SHA-256。可读UI／场景参数直接复用；加密Lua没有宣称已恢复为原始可读代码。胜负文字的缩小时序是按用户视频适配。

验证包含83项规则／协议测试，实际Unity渲染检查，以及真实时钟的AI等待样本。截图为合成测试局面的实际渲染；AI时序图是测试记录，非游戏内新增提示。安卓真机／多手机热点联机未测。
