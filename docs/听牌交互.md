# 听牌交互（Unity 0.5.20）

| 玩家操作/状态 | 提示行为 |
| --- | --- |
| 选中准备打出的牌，打出后能听牌 | 自动预览该出牌对应的待牌，包括无役标记 |
| 选中打出后不能听牌的牌 | 收起预览，不回退到原手牌的待牌 |
| 未选牌，已经听牌 | 平时收起提示 |
| 短按右侧「听牌提示」 | 不切换开关，不常驻显示 |
| 按住按钮约 0.35 秒 | 显示当前待牌；有选牌时优先显示该合法出牌的预览 |
| 松开、拖离按钮 | 收起长按提示；拖回按钮也不会重新开启，需重新按住 |
| 切换后台、失去焦点、返回大厅或进入结算 | 清理长按状态 |

自动预览沿用房主提供给当前玩家的 `discardHints`；长按查看使用 `waitDetails`。仅修改 Unity 客户端触发方式，不改变听牌、无役、立直及振听的规则判定。右侧按钮是只读交互，不受状态轮询 `Busy` 限制。按下起于该按钮的整个手势被捕获，移出后在手牌上松开也不会触发出牌。

实际 Unity 验证覆盖四种比例的选牌预览/非听牌选牌，以及 1688×780 和 844×390 的短按、长按、松开、拖出、拖回和失去焦点。十三面待牌仍完整显示；立直选牌、无役标记、振听、流局、动画及结算的既有完整回归通过。自动化手势输入驱动实际客户端处理和实际 GUI 渲染，未执行安卓真机触摸验证。
