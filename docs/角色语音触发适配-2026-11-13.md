# 角色语音触发适配

本轮使用工程已保存的 122 名角色、16,226 条语音定义与已有角色包。每名角色 133 条，其中 110 条对应本作已有事件，另外 23 条缺少对应玩法或养成系统，继续支持语音页手动试听。没有修改或发布角色资源包、公开下载 URL 或摘要。

## 播放时机

| 语音 | 本作触发时机 |
| --- | --- |
| 普通登录 | 冷启动大厅遮罩退去后播放一次；切换菜单、恢复房间不重复登录语音 |
| 大厅交互 1–8 | 点击大厅角色、宿舍角色、切换雀士；使用全部八条可播放定义轮换，保留各角色的实际路径 |
| 进入友人房、房内准备 | 本机进入房间、本机由未准备变为已准备；状态轮询不重复 |
| 对局开始 | 整场开局入场演出结束后，播放本机本场角色语音；续局和重连不重播 |
| 吃碰杠、拔北、立直、和牌 | 保留原来的动作演出同步播放，并优先于特殊提示 |
| 役种、宝牌、满贯至六倍役满 | 保留结算顺序；按语音目录解析历史别名及子目录 |
| 听牌、未听牌、流局满贯 | 流局展示播放本机状态；自动演出等待该条语音播完，再进入分数页 |
| 九种九牌、四风连打、四家立直、四杠散了 | 对应途中流局展示；有发起者时使用发起者角色，否则使用本机角色 |
| 终局一位 | 最终排名页的一位角色；最后一局自己和出倍满以上用高分版本，否则自己荣和用荣和版本，其他情况用普通版本；缺少变体时退回同角色普通版本 |
| 连续打出相同牌 | 本机连续三次弃同一种牌，赤五与普通五视为相同牌 |
| 打出宝牌 | 本机打出赤宝牌或当前明示宝牌；三麻一／九万指示转换单独处理 |
| 余牌不足十张 | 牌山从十张以上降到九张时，播放本机角色提示 |
| 役满、倍满／三倍满听牌 | 本机最新已提交弃牌后的听牌信息达到条件；含公开宝牌及拔北，排除里宝牌 |

终局高分变体的选择是本项目制定的规则，未声称已复刻原版客户端的具体阈值。特殊提示均只在本机播放，各类型每小局最多一次，不向房间广播自己的暗手或听牌。吃碰杠、和牌报役会取消提示语音；暂停、换小局、离房清空待播，提示超过十秒作废。自动语音期间平滑压低背景音乐，结束后恢复用户音量。
