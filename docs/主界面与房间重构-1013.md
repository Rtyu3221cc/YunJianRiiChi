## 已实现的流程

大厅按比例裁切背景，保持一姬立绘、用户区域、段位场／比赛场／友人场、设置与截图入口和文档保留的底部入口。文档红框中删除的项目不绘制，也不随页面跳转恢复。三张场次招牌依次入场，返回大厅重新播放飞入效果和原版音效。

三个场次入口均进入创建／加入选择页，页名分别显示对应场次。创建页只保留三人／四人、东风／半庄及高级设置开关，删除特殊比赛模式和出牌时间整行，收紧基础表单。高级区使用原版分隔线及滚动条资源，并支持拖动滚动。

加入弹窗提供六位数字键盘、清空、删除和确认。默认通过 UDP 发现同一局域网的对应房间号；广播被热点限制时，可展开连接设置填写房主 IPv4 地址及个人恢复码。房间号仍由服务器验证，发现报文不包含房主密钥、座位令牌或手牌。

等待室显示实际房间号和实际规则。房主可添加电脑、踢出电脑或真人、复制邀请信息；真人可准备或取消准备。新创建的房间必须座位齐全且真人准备后才可开始，开始后交给原 0.5.39 牌桌流程。旧等待室存档保留原有开局条件。

在等待室返回大厅时，房主解散尚未开始的房间，真人退出并释放座位；有确认弹窗，点击弹窗外、关闭或返回可取消。被踢出的旧座位凭据和恢复码失效，可重新加入新座位。创建不会悄悄恢复或覆盖旧房间；个人设置中的“继续本机房间”提供显式恢复入口。

## 高级设置边界

根据本次确认，只开放已有三／四人、东风／半庄和赤牌选项。其他项目展示实际默认规则：

| 项目 | 四人麻将 | 三人麻将 |
| --- | --- | --- |
| 初始点数 | 25000 | 35000 |
| 一位目标点数 | 30000 | 40000 |
| 赤牌 | 3 赤或无赤牌 | 2 赤或无赤牌 |

| 古役 | 关闭 | 关闭 |
| 食断 | 开启 | 开启 |

规则说明使用 APK 原版四人／三人图文资源，并展示实际规则及役种说明。一局、人机单局和可调计分规则没有接入本次界面。

大厅飞入、普通飞入和按钮音效已接入 APK 原文件；默认大厅背景音乐尚未在所供 APK 中找到。本测试包先保持 APK 来源边界，不添加外部大厅音乐。原有牌桌音乐保持原样。
