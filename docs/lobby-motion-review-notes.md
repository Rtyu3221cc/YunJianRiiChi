# 大厅切换与创建页预览

本轮仅本地修改和 Unity 渲染预览，不上传 Git、不生成 APK、不运行单元测试。牌桌与打牌代码不在修改范围。

友人场入口先退出三个场次招牌，再播放原版标题及卡片轨道。`UI_Lobby/page2/content` 的原版 Mask 映射为卡片内容裁切区；`content/btn0` 是创建、`content/btn1` 是加入，加入先绘制、创建后绘制，按各自原版轨道和素材比例换算位移。标题透明度也沿用原版曲线。

友人场返回大厅保留立绘和周边控件，只重新播放主招牌。创建页返回先淡出菜单，再播放整个大厅的入场：`container_top` 顶部滑入、底部按钮逐项上移、左下按钮上移、立绘按 `anim_alpha` 的延迟和横向位移进入。三个主招牌的时序根据提供的视频校准；其 page0 节点没有对应 AnimationClip，因此不将该部分描述成已恢复的原版脚本。

方向复核修正：原版人物从右侧向左入场，越过目标位置后轻微回弹；`anim_alpha.indistance.x=300` 表示起点在目标右侧。三个场次招牌从左侧依次向右入场，并各有斜向位移和回弹。先前人物的减号与招牌的正向横移均与视频相反，已更正。招牌使用逐帧图像跟踪得到的各自位置／透明度轨道，不再套用统一的单向减速。

人物的实际视频轨迹对应约 0.15 秒延迟、0.25 秒 OutBack 位移；原始 prefab 的默认 `delay_in=0.2` 仍保留作为来源证据，预览使用视频中实际生效的延迟。原版头部位置从最终位置右侧约 78 像素移向左侧约 16 像素的超调，再返回落点；三个招牌均先在最终位置左侧出现。

招牌退场也重新对照：原版先轻微放大，再按各自原始锚点缩小并淡出。使用 `UI_Lobby/page0` 中三块牌各自的 pivot，取消原来的统一上移；进入友人场的下一阶段等待这段退场完成。并排视频按原版实际点击发生的帧重新对齐。

动画数据和逐图布局位于 `Majsoul/Lobby/garden-motion.json`、`sign-entry-motion.json`、`create-label-layout.json`。`scripts/import-lobby-resources.py` 可重新提取原版曲线、预制体配置及图标／文字图片的透明边距数据，并保留视频测量轨道的出处记录。图标和文字仅按这四组素材各自的可见范围校准，不设置其他字体的全局偏移。

创建页背景、上下分隔线使用物理屏幕的完整宽度；标题和交互控件继续使用安全区。预览包含左侧及右侧约 5.5% 的安全边距模拟。

`LobbyMotionPreview` 用固定的编辑器 UI 时钟输出真实 Unity 渲染帧，以 60 帧／秒编码为无声 MP4；提供三个流程、完整大厅入场、原版并排对照和静态截图。未连接真实手机。
