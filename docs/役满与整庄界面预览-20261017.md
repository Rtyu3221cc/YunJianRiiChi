# 役满与整庄界面预览

本轮修改基于本地 0.5.44 源码，未生成新 APK，未运行单元测试，未提交或推送 Git。

- 役满机会、役满确定：从用户提供的 `Majsoul_4.0.16_MC.apk` 提取简体中文粒子图，保留完整的 6 层、8 层粒子组件、材质、原始贴图与 Android 编译着色器。通过独立叠加摄像机沿用原混合方式显示，避免透明中间纹理造成黑色方块。
- APK Lua 仍是加密内容，未声称已恢复或直接复用 Lua 源码。本项目离线计分引擎根据本人的手牌评估每种听牌的荣和、自摸役满结果；部分和牌方式为役满时提示机会，固定听牌全部为役满且非振听时提示确定。每手牌每个等级最多播放一次，重复轮询不会重复播放。
- 参考视频牌型 `m999p3444s777z666` 听二、三、五筒，仅三筒是役满；`m1999p444s777z666` 为一万单骑役满。实际公开视图已用于 Unity 演示，未读取其他玩家暗手。
- 整庄：房间参数 `rounds=4`，三人打东南西北共十二个常规局，四人共十六个常规局。保留连庄、击飞与终局规则，以北场为最大场风，避免延长进入不存在的第五场风。三人北三局、四人北四局均在非连庄结算时结束。
- 加入房间失败与相关帮助文字统一使用“同一 Wi-Fi 或同一热点”。
- 大厅音乐使用用户试听确认的《金秋送爽》秋季原曲，来自雀魂官方资源，保持大厅循环播放以及原音乐开关、音量设置。来源与 SHA-256 记录在 `unity/Assets/Resources/Majsoul/Lobby/Audio/autumn-source.json`。
- 役种结算：役种与点数展示完成后显示 `确认(3)`、`确认(2)`、`确认(1)`，三秒后推进；手动跳过展示后也从三秒开始。双响逐位处理，后续分数结算仍沿用原有确认规则。
- 听牌：保留之前居中的牌面、剩余张数及无役样式，不显示“打哪张牌”的列表。存在可听牌的舍牌时显示原按钮；选中相应手牌后自动显示原听牌面板，提交舍牌后收起；后续轮询不会自动重开本次面板。
- 二维码和邀请弹窗宽高均放大 25%，二维码由 352 调为 440 个设计像素，弹窗由 852.3×660 调为 1065.375×825，保持二维码留白与确认按钮间距。

本地预览目录：`dist/preview-20261017`。编译与短界面演练日志位于 `build/review-1017b`，包括原按钮显示、选牌听牌、出牌收起、三秒确认、两种屏幕尺寸二维码和两段各 1.8 秒的实际粒子演示。
