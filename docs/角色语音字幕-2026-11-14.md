# 大厅与宿舍角色语音字幕

参考用户录像 `../video/1102/角色語言字幕.mp4`（4.889 秒，旋转后 2374×1080；SHA-256 `0af577a1db9dfe856497ff0c6a4414325a0ff942724609b5afde9f3543582050`）。录像展示大厅、切入宿舍后两段不同台词；字幕位于角色下方，半透明黑底、白字、左上对齐，约每秒 20 字逐字出现。录像没有包含语音自然结束，不以录像推断结束时刻。

## 实现

- `CharacterVoiceCatalog.Line` 根据实际语音路径查文本，避免八条交互语音、普通／满绊登录语音串词。沿用现有简体中文目录，不另写台词，不修改角色包 URL、摘要或资源发布。
- `CharacterVoices` 成功启动大厅类语音后才建立字幕；`CharacterVoiceCaption` 使用同一个起止时钟，替换 `{name}`，按文字元素逐字显示，保留代理对和组合字符。停止、静音、换语音、离开宿舍／进入角色选择和应用暂停清理字幕；自然播完后清理。
- `LobbyController.Subtitles.cs` 复用原有 `mask_dialogue` 九宫格。1080 高的 UI 坐标下，字幕框 634×234、字体 28，内容自动换行；超长台词跟随末尾，避免文字越出框。16:9 下向左收让，避开右侧宿舍面板。绘制不接收点击，连续点击立绘仍能换语音。
- 大厅只在主页、宿舍只在角色立绘页显示；设置等遮罩、角色选择、装扮预览及对局中隐藏。语音试听页沿用已有全文显示，不重复叠加浮动字幕。
- 只增加语音已存在时的字幕，没有新增送礼、好感度或四川玩法的触发事件。

## 验证方式与产物

`scripts/test-character-subtitles.ps1` 在缓存暂存工程运行实际 Play 模式，使用隔离的测试产品设置、验证过 SHA-256 的未来 Windows 角色包和预览存档；保留／恢复会被装扮页写入的预设键。`tests/CharacterSubtitleReview.cs` 位于暂存工程 Editor 目录，不进入 Android。

实际运行共 2,588 项检查通过，其中 122 名角色的 2,562 条大厅类语音目录与路径精确匹配。运行结果、实际声音播放状态及六张 2374×1080／1920×1080 截图记录于 `build/character-subtitles-r36/report.json`。核对内容包括立绘真实点击、逐字递增、换台词、189 字长文本末尾跟随、静音、找不到音档、自然结束、换角色／离开页面、暂停及试听页不重复显示。截图由 Unity Game View 实际渲染，未逐一渲染全部角色。Node 202/202、Python 8/8 通过。
