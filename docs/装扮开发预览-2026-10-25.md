# 云间日麻装扮开发预览

本轮按用户要求制作实际效果图和视频，暂不生成 APK、不运行正式测试、不提交或上传 Git。
版本仍为 Unity 0.6.10 / versionCode 58；开始开发前的 Git 基线是 `bfed191`。

## 当前可以查看的内容

- 宿舍的“装扮”页签已可进入；沿用原版背景、金框、分类框、物品框、选中角标和眼睛预览按钮。
- 不制作参考图红框中的多方案槽位和方案名称／重命名。
- 分类列表可拖动滚动。先接入桌布、牌背、牌面、头像框和静态大厅背景，每类两件，共十件。
- 点击物品修改待保存的搭配；点击眼睛预览，点击保存装备；保存后按钮显示“使用中”。
- 桌布／牌背／牌面的预览使用独立相机，并复用实际牌桌的 `OriginalTiles` 网格和 Shader。
- 装备后的桌布、牌背、牌面应用到实际牌桌；头像框应用到本机座位头像；大厅背景应用到大厅。
- 立直棒、和牌特效、立直特效、鸣牌指示、手的样式、立直音乐先保留分类及原版占位显示，不宣称已经完成装备切换。

录制使用临时装备和角色偏好，结束后恢复原编辑器偏好。牌桌展示使用固定展示场景；不将它表述为手机实测或局域网测试。

## 资源来源

`scripts/import-wardrobe-preview.py` 从现有 `Majsoul_4.0.16_MC.apk` 提取 39 个原版 UI Sprite 及牌背、牌面、头像框图像；共保存 59 个 APK 图像的来源记录。
原对象路径、bundle、pathID、尺寸和 SHA-256 在 `unity/Assets/Resources/Majsoul/Wardrobe/provenance.json`。

桌布和背景复用工程已经导入的原版素材；既有吃瓜桌布的 CDN 来源保留在 `Majsoul/reference-skin.json`，没有把它改称本次从 APK 提取。
保留原始透明画布和图集尺寸；猫耳框用单独的头像窗口坐标对齐，不裁改原图。

本轮资源仅用于小规模内置预览。后续扩充时应将非内置素材迁出 Resources，制作独立版本化装扮包，避免全量装饰进入 APK。

## 主要入口

- `LobbyController.Wardrobe.cs`：分类、物品、待保存搭配、预览和保存。
- `WardrobeCatalog.cs`：装扮资源目录与本机装备偏好。
- `WardrobeTablePreview.cs`：独立牌桌预览及资源释放。
- `OriginalTiles.cs`、`TableRenderer.cs`：选定牌面、牌背和桌布的呈现接入。
- `RiichiClient.cs`：本机座位的头像框呈现。
- `WardrobeAssetImport.cs`：仅本次装扮纹理的导入参数。
- `WardrobePreview.cs`：编辑器截图／录屏入口，不包含测试套件。
- `scripts/run-wardrobe-preview.ps1`、`scripts/package-wardrobe-preview.py`：生成实际画面并汇总为视频和本地画廊。
