# 界面与扫码预览 · 2026-10-17

本轮仅做源码修改、编译检查和实际 Unity 视觉预览。没有运行单元测试，没有生成 APK，没有提交或推送 Git。版本号保持 0.5.43。

- 吃牌组合和听牌面板：九宫格共用取整后的物理像素边界，并将采样限制在各片内，消除白色拼接缝。
- 听牌：改为按下／抬起切换 ON/OFF，开关样式沿用 AI 托管按钮，位置在其上方；牌面提示保持手牌上方居中，拖出按钮取消，不触发舍牌。
- 有缓存中的进行中牌局时，首页“牌局”灯笼显示 APK 的 `redpoint_1` 原图，原有回座流程保留。
- 红点以最新提供的原版“公告”灯笼为准，使用 APK 的 51×51 节点大小及中心锚点 (-65.5,-7.5)，换算为灯笼内 GUI 位置 (-14,90)，并随灯笼点击缩放保持相同的相对位置。
- 创设房间：根据提供的视频补齐大厅淡出、创建面板淡入，保持现有高级规则默认值及手动文字位置。
- 邀请二维码：准备室分享、空座邀请及牌桌星标共用入口；原邀请说明、地址和房间号文本由二维码替代。二维码含公开房间号及局域网地址，不含座位 token、恢复凭据或房主密钥。二维码与四周留白在弹窗内完整显示。
- 扫码：加入弹窗新增与确认同大小的黄色按钮；取景界面可切换摄像头或 Android 系统相册。格式错误使用中号弹窗提示“当前二维码不正确”。有效二维码先核对原房间，再沿用现有加入 API。
- 摄像头未开启／正在开启提示在黑色取景区域内水平、垂直居中。

实际编辑器预览中完成了图片解码、查询隔离房间、加入准备室的流程；Android 相机权限、摄像头画面与系统相册选择尚未真机演练。只编译了 Android 相册选择源文件，没有构建 APK。

资源：红点为雀魂 APK 内的 `redpoint_1`，记录在 Lobby/provenance.json。二维码编解码使用官方 ZXing.Net 0.16.11，Apache-2.0 许可证随源码保存。
