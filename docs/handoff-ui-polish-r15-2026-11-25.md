## 角色名称

准备页原来直接用换行拼出竖排字符串，字体行高导致长名字顶住横幅上下边缘。现在复用宿舍的 `VerticalCharacterLabel`，在原名字区域内上下各留12设计单位，逐字居中。

同一方法同时限制字号和字距，长名不会靠字距压缩导致文字重叠；普通名字保留原字号，最长8字“鲁鲁修·兰佩洛基”、7字“伊芙·克里斯特”、6字英文 Archer，以及用户示例的小鸟游雏田、北见纱和子、花语青、Saber均覆盖。仍使用 R12 原版姓名字体，没有改字库或回退到其他字体。实际界面滚动遍历全部127个角色，记录逐字布局并检查总高度与相邻字距；两种比例均通过。

## 宿舍与房间装扮统一

新增 `LobbyController.WardrobeShared.cs`，两页调用相同的预设列表、名称、使用按钮、物品网格及标题／预览绘制。原版素材、边框及字体保持，不重绘资源。

- 预设分页：沿用准备页原版金色选中／暗色未选中样式和绿色使用标记，宿舍也使用同一绘制。10个预设保留，列表支持滚轮／拖动；两页都检查了滚动至第10个并选择。根据两页可用列宽适配九宫格，中间区域伸缩，素材边角保持。
- 预设名称：按用户要求改为宿舍式只读标题，移除房间页铅笔和改名弹窗入口。不会清除以前保存的名称，默认仍显示“预设1／预设2…”；`WardrobePresets.Rename`数据方法留存，不再由本轮 UI 调用。
- 使用中：共用宿舍的灰色禁用状态和220×62尺寸；切换到其他预设时显示“使用”。只查看预设不会立刻穿戴；实际使用后才同步房间，未下载物品仍按既有规则保留当前装扮，并有提示。
- 图标网格：共用143×143卡框、137×137图像、178横向中心间距、182纵向中心间距；根据面板宽度整体居中。统一选中四角、下载大小／进度文字和手型名称。当前房间卡框也使用宿舍同一素材。较长列表仍需滚动。
- 类型名与预览：两页共用左对齐标题、右侧60×60眼睛图像及76×76点击区、相同内边距和分隔线。房间继续保留原有5类静态预览限制，宿舍的特效／音乐／牌桌预览行为保留；本轮统一样式，不扩大房间内3D预览范围。
- 同一方法处理图标选择及下载回调；房间仍调用 `PublishCharacterSelection`，保留 R14 的轮询排队与资源准备锁定，宿舍仍编辑当前浏览的预设。

宿舍预设列加宽以容纳原版分页形状；准备页和宿舍面板外框仍按各自原布局定位。共用的是控件样式和图标尺度，不将两种外框强行改成一样宽。

## 三人场点数结算

根因位于 `NativeReviewLayout.ScoreSlot`：原来三麻只把相对座位2映射到左槽，座位1仍落在四麻右槽；但牌桌上座位1实际是对家。现在与牌桌及拔北共用同一个 `Physical(relative,n)` 映射。

| 相对座位 | 三人实际方位／原版槽位 | 四人方位／槽位 |
| --- | --- | --- |
| 0 | 自家／0 | 自家／0 |
| 1 | 对家／2 | 下家／1 |
| 2 | 上家／3 | 对家／2 |
| 3 | 无 | 上家／3 |

结算卡和收付点数箭头均通过同一映射，三麻不会再占用空的右侧槽位。移除 `ResultPresentation` 中一个未使用且同样错误的旧中心位置函数。没有改点数、排名算法或牌桌头像位置。

验证使用公开 DTO 形状的合成结算场景，直接调用实际牌桌与结算绘制，比较真实 `SeatAngle`、信息卡槽位与收付箭头；覆盖三麻3个视角、四麻4个视角各自的荣和／自摸／流局，共21场景／比例。录像展示两种比例的代表场景；这不是实际手机对局记录。
