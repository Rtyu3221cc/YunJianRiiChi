# 0.5.34 立直摸牌时序与供托说明

立直手牌的颜色按展示进度更新：上一家的出牌／立直棒等队列未完成时保持正常色；自家新摸牌出现并完成短暂入手展示后，才将不可打的手牌置灰。轮询重建不重播摸牌，也不会提前置灰。新增摸牌展示期间的操作保护。

合法摸牌按当前操作选项匹配，重新刷新颜色与点击目标；四条等可打牌保持正常色。保留摸切／手切的重复牌区别；当旧主机省略摸切标记、且手中只有唯一一张该牌时，只绑定主机实际提供的合法操作。可杠牌、可拔北牌和岭上新摸牌仍保留正常色。

用户图中的增分13000是和牌12000加一根供托立直棒1000。前两张图左上角立直棒计数为1；点炮者付12000，供托是此前已经交到场上的分数，不再向点炮者扣一次。计分引擎未改变；结算卡片新增“和牌 +12000  供托 +1000”的来源说明。赢家收取立直供托亦见[EMA规则3.4.3](https://mahjong-europe.org/portal/images/docs/Riichi-rules-2025-EN.pdf)。

实际Unity专项检查覆盖上一家动画、轮询、摸牌结束、可打四条、唯一牌旧格式、可杠／拔北以及0／1／2根立直棒的结算。1根供托的例子：17500 → 30500，赢家增加13000，点炮者减少12000。截图是合成测试局面的真实渲染，不是用户截图重绘或安卓真机截图。
