# 0.5.33 手牌中轴与副露位置

1. 自家副露在0.5.32基础上再向下移动8个屏幕像素；保留0.5.31放大后的实际牌面／描边宽度及手牌尺寸。
2. 无遮挡时，自家手牌中心对齐牌桌和中央分数盘的投影中轴。原实现使用 `Screen.safeArea.center.x`，而牌桌相机以整个视口为中心；左右安全边距不相等时，两者会错开。此次改用牌桌原点的屏幕横坐标，安全区域继续用于裁切约束，有副露等公开牌发生实际碰撞时仍按原逻辑避让。

专项实际Unity渲染复现了1751×799画面左侧90像素安全边距造成的45像素偏移；修正后左右两种不对称边距的手牌中心都对齐牌桌中轴，手牌宽高不变。检查三麻／四麻、13张／14张手牌及936×435、1280×720、1751×799、1024×768四种分辨率。前三种常用横屏尺寸的副露底边再下移8像素；4:3窄画面保留原有上移避让，以免副露与手牌重叠。1～4组副露均检查手牌／头像遮挡与裁切。
