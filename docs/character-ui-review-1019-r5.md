# 雀士弹窗修正 R5

本轮按四张标注图修改，交付当前 Unity 工程实际渲染的效果图。不编译 APK、不上传 Git，不改牌桌。

- 切换雀士／随机页共用的主背景与外框：九宫格切片使用共享的物理像素边界，消除左侧与底部露出大厅背景的细缝。
- 顶部两个页签：仅裁掉原始贴图左右各 10px 阴影留边，使可见按钮紧邻，标题位置不变。
- 服饰展开框：三角底边接到原版边框；高度 180→154，头像底部空白收紧，横向拖动保留。
- 使用中：原 APK 灯笼图片中的文字局部右移 2px，灯笼外形和位置不变。派生脚本与来源记录为 `scripts/prepare-character-review-r5.py` 和 `Characters/roleset-refinements-r5.json`。
- 所有青色角标中的服饰数量文字右移 2px，三角底图位置不变。

随机页星标过滤单独核对：全部四人→仅两名星标→全部四人；无星标时显示空提示；切换过滤关闭展开框；仅星标时服饰仍可配置。左侧三名雀士、四套服饰的候选集合在全部步骤中不变，未星标但已选的一姬继续保留在左侧。

核对是编辑器实际运行画面与验证选择入口，滚动使用共用运行时手势路由；未做 Android 真机触摸验证。1750×800 与 1280×720 的图片见 `dist/previews/2026-10-19-character-system-r5/index.html`，可重复入口为 `CharacterReviewR5.Run`，产物记录位于 `build/character-review-r5/artifact-checks.json`。
