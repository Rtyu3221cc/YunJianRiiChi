# 装扮 R6：动作、方向、时序与视频预览

本轮按用户要求先看视频：不生成 APK，不提交或上传 GitHub。已有 0.6.13 安装包不包含本轮修改。

## 九项反馈的处理

1. **手部立直动作**：原导出只保留携牌节点的位置，播放时直接使用落地牌的旋转。现增加原骨骼携牌节点的逐帧四元数，在宣言动作中插值，并以落地关键帧校准，交接时仍精确对齐牌河。猫爪／橘猫爪、人手、汪爪与男性手均覆盖。完整视频由引擎产生的公开 `discard(riichi)`、`riichi`、`riichi-stick` 事件驱动，同时展示宣言牌与放棒。
2. **荒牌流局闪现／重播**：牌列在创建时就应用当前摊牌姿态；等待前一动作时保持初始站立姿态。轮询重建沿用同一摊牌时钟，身份增加 `handSeq`，避免先显示平放牌后再播放翻牌。
3. **雷击方向**：原 `effect_hupai_default` 就包含雷击，资源名不是方向问题。实际粒子速度检测定位到 Box 发射轴的转换；显式反转 Box 速度完成 Z 反射。四视角均验证为向下。用 `BakeMesh` 对照原始拉伸着色器后，保留原零锚点和贴图 U 长轴，移除分析期间尝试的纹理旋转。
4. **BGM 渐停／渐入**：按照原 `AudioMgr.StopMusic`／BGM 管理器的默认 1000 ms 时长，从和牌开始一秒渐停；结算和轮询期间持续静音，下一局身份改变并开始牌局后，一秒渐入。普通 BGM 和立直音乐都受此包络控制，试听独立。视频声音来自 Unity 实际混音输出。
5. **角色／装扮页签**：两页共用原角色面板的右边界和页签坐标；切换时面板横向展开／收拢，原内容先退场、新内容后入场，立绘和姓名牌淡入淡出。原角色面板尺寸保留。
6. **关闭三类独立预览**：和牌特效、立直特效、鸣牌指示的宿舍预览眼睛入口关闭，选择和保存继续可用。牌桌视频用于观察实际表现。
7. **拔北描边**：排列步长改为与副露相同的 `MeldSlot(false)`，计算实际可见描边宽度；提供三人全部座位的画面。
8. **新增样例**：和牌增加原版旋风、樱花；立直增加原版苍火、蝙蝠桀桀；手部增加原男性手与汪爪，每种均导出五套原始动作。本地配置只有四款鸣牌指示，新增樱瓣、蝙蝠明确标注“试装”，使用原粒子形状与曲线组合，并缩小范围以保持牌面可读。目录共 11 类、36 件。
9. **多余三角**：原 `DesktopMgr.ShowChiPengEffect` 加载当前装备的 `mingpai_zhishi` 资源并跟随可响应弃牌。移除额外绘制的黄色三角；普通引导的箭头来自其自身预制资源，仍正常显示。特殊角色技能的 `ShowMakaChiPengEffect` 是另一入口，未混入普通鸣牌指示。

## 源码核对中的区别

- 原配置 `effect_liqi_ice`、`effect_liqi_bianfu` 的 `sargs[0]` 是 `shu`，原脚本选择 `Dapai`；火焰与苍火为 `heng`，选择 `LiQiPai`。因此冰霜／蝙蝠的视频中宣言牌仍采用普通出牌分支，之后有专门的 `LiZhi` 放棒动作。
- 五种手型从原动画读取携牌旋转，而非按手型名称硬编码转角。新增男性手和汪爪从原场景、骨骼、绑定矩阵和动作文件烘焙；人手既有顶点动画二进制逐字节保持一致。
- 新增樱花的花瓣包含逐轴速度曲线，已补齐曲线导出和运行时模块，另复录和核对了八个视角。和牌的完整源层级、渲染模式和尺寸曲线继续保留。
- 四视角指同一公开弃牌／和牌事件从四个座位观察。己方弃牌的观察仅用于编辑器检视，不创建自己吃碰自己弃牌的选项。

## 交付文件

`dist/previews/2026-10-27-wardrobe-r6/`

- `index.html`：普通预览页，含原版参考视频。
- `手机版完整视频预览.html`：视频内嵌单文件，可离线打开。
- `bgm-fade.mp4`：带实际声音的和牌、结算静音与下一局渐入。
- `hands-all.mp4`：五种手型完整立直及冰霜分支。
- `wins-all.mp4`、`riichi-all.mp4`、`callouts-all.mp4`：各类四视角合集。
- `draw-polling.mp4`、`tabs-switch.mp4`、`north-outlines-close.mp4`：流局、页签与拔北描边。
- 每款的四宫格、局部、原分辨率单视角 MP4，以及实际截图、检查记录和媒体清单。

视频为 Unity 编辑器渲染的公开测试场景，不能当作 Android 真机通过。BGM 使用 Unity 的 [AudioRenderer](https://docs.unity.com/en-us/engine/6000.6/script-reference/unityengine/audiorenderer/getsamplecountforcaptureframe) 录制实际输出；网格方向通过 [ParticleSystemRenderer.BakeMesh](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/ParticleSystemRenderer.BakeMesh.html) 读取。

本段 BGM 为独立试听，录制时通过设置接口将语音和动作音效静音，以便判断音乐变化。最终音频约 11.99 秒：结算采样区间的 RMS 为 0，下一局采样区间恢复非零。该设置只在编辑器预览期间使用，结束后恢复。

最终检查：150 项运行／几何／像素／音量断言、10 项相关 Node 测试和 144 项原数据断言通过；111 个 MP4 完整解码通过，两份页面脚本语法及本地媒体链接通过。捕获共 5,236 帧。旧 0.6.13 APK 摘要保持不变。没有自动化操作本地文件浏览器页面。

## 重现与证据

- 输入配置和代码摘录：`build/wardrobe-r6-study/`，含原始着色器、手型动画配置、完整物品配置和提供的视频联系表。
- 原资源导入：`scripts/import-wardrobe-r6.py`，不执行旧的重置目录脚本；来源和原始摘要写入 `Wardrobe/provenance-r6.json`。
- 公开事件 fixture：`scripts/wardrobe-r6-fixtures.cjs`；录制入口：`WardrobeR6Review.RunFull`。
- 原数据核对：`scripts/verify-wardrobe-fidelity-r4.py`。运行检查、实际像素检查、音频通道检查与后续补录均保存在本轮捕获记录中。
- 打包：`scripts/package-wardrobe-r6.py`。最终解码、页面脚本、资源链接与旧 APK 摘要检查见预览目录的 `validation.json`。
