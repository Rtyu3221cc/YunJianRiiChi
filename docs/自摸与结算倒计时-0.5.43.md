# Unity 0.5.43 自摸牌与结算确认

2026-10-16。接续 0.5.42 及本地全员托管结算修复。

## 两处修改

1. 自摸动作的原始带牌轨迹会横向扫过摊开的手牌，动画牌同时使用清空深度的覆盖相机。现在牌与手部动作一起对齐预留牌位，牌沿该位置垂直起落；动画牌采用正常牌桌深度，手臂保留覆盖渲染。沿用目的牌的实际模型、尺寸、朝向和落点，交接时只显示一个模型。没有调整全局牌大小或静止牌列。
2. 点数转移／排名演出完成后，右下角保持暗色按钮，显示“确认(3)”“确认(2)”“确认(1)”，满 3 秒自动执行确认；也可提前点击。“确认”与“返回大厅”均采用 31 号字。普通结算发送当前 handSeq 的 ready；终局先进入最终排名页，原“下一局(9)”的 9 秒倒计时继续生效。未完成演出时保留“跳过”。自动推进统一在 Update 运行，GUI 重绘仅绘制和接收手动点击。

## 同步包含的上一轮修复

- 在线真人即使启用托管，也在本机完整演出后确认结算；双响依次播放两名赢家，最后再播放共用点炮牌特效。
- 等待和牌粒子真实结束，换局清理旧提示、粒子、排队手部动作、语音、音效和旧事件。
- AI 等待为随机 700–1000ms。本轮修正仍按旧 500–800ms 检查的测试，并增加三／四人普通／终局的在线托管确认与换局清理测试。
