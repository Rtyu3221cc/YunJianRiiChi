## 规则

- **段位表**：初始分、升级分与末位减分（东风／半庄）逐项按视频录入 `unity/Assets/Scripts/RankRules.cs`。三麻从雀豪2 起减分不同。魂天每级初始 10 魂珠、升级 20 魂珠，魂珠变动按视频脚注；同桌全是已公布魂天的真人时翻倍（AI 不算）。
- **段位分** = 顺位分 + 素点。素点 = (终局点数 − 起始点数) ÷ 1000，四舍五入且远离 0；四麻起始点数 25000，三麻 35000。
- **顺位分**：视频没给，是我们自定的值，可在 `unity/Assets/Resources/Majsoul/Profile/rank-rules.json` 调整。默认：
  - 四麻：东风 +40/+20/0，半庄 +80/+40/0；
  - 三麻：东风 +50/0，半庄 +100/0；
  - 末位按段位表减分；整庄按半庄计算。
- **升降**：
  - 每局最多变动一级。
  - 达到升级分即升一级，分数取新级的初始分；低于 0 降一级，取那一级的初始分。
  - 初心不降级，最低 0 分。雀圣3 升入魂天 Lv1（10.0）；魂天 Lv1 降级回到雀圣3（4500）。
- **计分范围**：只有段位场（`ranked`）改变段位，四麻、三麻各有一份段位。友人场、比赛场只记录对局和统计。
- **同分名次**：按离起家近者排前，剩余供托归第一名。引擎原来按座位号决定供托归属，这次一并改为按同一顺序。

## 实现

| 部分 | 文件 | 内容 |
| --- | --- | --- |
| 引擎 | `app/src/main/assets/engine.js`（Android 副本逐字节相同） | 统计每座位的手数、和了、自摸、放铳、立直、副露、和了巡目、打点、里宝命中、最佳一手和高光次数；终局时 `result.standings`（名次、点数、统计）与 `result.rules`；`players[].profile`（各自设备公布的段位和称号，AI 为 null） |
| 协议 | `unity/Assets/Scripts/RoomProtocol.cs` | `StandingView`、`SeatStats`、`BestHand`、`HighlightCounts`、`ResultRules`、`PlayerRankProfile` |
| 规则与档案 | `RankRules.cs`、`PlayerRecord.cs`、`PlayerTitles.cs` | 段位计算；本机档案存于 PlayerPrefs `riichi.player.v1`（9 位 ID、四麻／三麻段位、称号、各页签×人数的最近 100 局、累计、最佳一手、高光）；每局只记录一次 |
| 记录 | `RiichiClient.Session.cs`、`RiichiClient.cs` | 首次看到终局即记录（必须在终局页 9 秒自动确认之前）；记录后用 `profile` 请求把新段位和称号同步给牌友 |
| 终局页 | `ResultPresentation.cs` | 各家素点，本家 PT 变化，底部段位条（升段／降段／友人场不计段位）；名次改用引擎 standings |
| 信息页 | `LobbyController.PlayerInfo.cs`、`LobbyController.cs` | 大厅头像打开。包括：立绘卡、四麻／三麻切换、称号、昵称、段位徽章＋星＋进度、段位说明表、三个页签（段位场／友人场／比赛场）、精选和牌、风格属性雷达、高光时刻、最近走势（10–100 局可调，默认 50）、ID 复制；另有称号簿、改昵称（1–7 字）、风格说明弹窗 |
| 真实段位显示 | `LobbyController.cs`、`MatchIntroduction.cs`、`RiichiClient.cs` | 大厅名牌、房间卡、对局开场与牌桌 HUD 不再写死雀士，改用真实段位和称号；AI 不显示段位 |
| 素材 | `unity/Assets/Resources/Majsoul/Profile/Rank/`、`Title/` | 37 张 PNG，复制自已有提取 `build/apk-rank-title-study/delivery/images`（本机 4.0.16 APK，来源和摘要见该目录 README 与 `source-manifest.json`）；脚本 `scripts/import-profile-rank-art.py`，清单 `build/player-info-r1/rank-art.json` |

- 称号是我们自定的 8 个（`Profile/titles.json`）：默认、首次到达雀士／雀杰／雀豪／雀圣／魂天、首次役满、累计 100 局。没有沿用雀魂的称号图（提取包里也没有独立的称号图）。
- 风格属性按本页签和人数的累计计算，每项 0–100：
  - 攻：和牌率与平均打点；
  - 防：放铳率越低越高；
  - 速：平均和牌巡目越早越高；
  - 运：自摸比例与里宝命中率。
- 改昵称首版没有 30 天冷却，也不消耗道具（目前没有道具系统）；新昵称在下次建房或入房时发给牌友。
- 每台设备只计算自己的段位，他人段位只显示对方设备公布的值。中途退出、没有看到终局的设备不会记录这局，目前没有离场惩罚。
