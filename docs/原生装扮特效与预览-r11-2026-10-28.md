## 来源及实现

当前 Edge 客户端为 WebGL **4.0.51**，资源版本 **0.16.289**。从正常寻觅详情预览进入效果，记录页面实际使用的公开资源索引与运行包，再定位目标资源及依赖。没有购买装饰或进行寻觅抽取。

本次资源补齐改变了此前“已索引基础 APK 未找到部分原生预制体”的状态：目前取得了本批和牌、立直的 Unity 原生预制体。保留完整粒子序列化模块、Renderer、层级、贴图、网格、材质实际参数。24 个主效果共 288 层粒子；问心之镰额外保存另外三个原预制体变体，共导入 27 个预制体。

黑洞、收割时刻、水之道、叮～、问心之镰及滚雪球包含编译动画。直接将运行时 AnimationClip 保存为编辑器资产会丢失曲线；本轮使用原始编译动画的 Unity Playable 实际采样，生成 60 Hz 的变动通道。保留模型运动、黑洞和雪球的 `_Alpha`，以及问心之镰的 `_MaskTex_ST`。原控制器采样速度均为 1。

源粒子的 Local 缩放忽略祖先比例，直接将整套效果挂在放大的游戏坐标下会造成尺寸和运动不一致。本轮在原始单位中模拟，通过匹配的相机位置、裁剪距离和投影合成到牌桌深度缓冲，保留原缩放与重力规则。该相机仅在原生特效存活时渲染。跟牌效果使用原生模型的牌面坐标换算，问心之镰保存四个方向的原预制体。

渲染按本批实际启用的 Legacy、Mobile 粒子及 FizzFX 主纹理／遮罩功能适配。此处没有声称恢复了雀魂完整原工程或 ShaderLab 源码，也没有把“参数齐全”当成全套画面已与原客户端逐像素等价。原版参考与云间日麻的牌局、目标牌位置及摄像机构图不同。

音频保留既有固定版本资源，来源在 `Wardrobe/provenance-r11.json` 单独标记；不将音频称为已经完成本次原版录音对照。

## 入口文件

- `scripts/collect-effect-reference.py`：仅采集实际观察到的公开资源与索引。
- `scripts/import-native-effects-r11.py`：原生层级、粒子、模型、材质与动画来源提取。
- `scripts/register-native-effects-r11.py`：目录、声音、立直绑定与房间装扮 ID 注册。
- `unity/Assets/Editor/NativeEffectR11Import.cs`：原生组件导入及原动画变动通道采样。
- `unity/Assets/Scripts/NativeParticleEffect.cs`、`NativeEffectMotion.cs`、`NativeEffectCamera.cs`：原单位播放、动画、相机合成。
- `unity/Assets/Editor/NativeEffectsR11Review.cs`、`scripts/package-native-effects-r11.py`：游戏内检查、录制与成片。

复现顺序：提取资源 → 注册目录 → Unity `NativeEffectR11Import.Run` → `NativeEffectsR11Review.RunStudy` → `RunFull` → 包装脚本。原始帧已清理，重新包装视频需要先重新录制。
