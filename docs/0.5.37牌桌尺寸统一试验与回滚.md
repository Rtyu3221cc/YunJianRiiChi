# 0.5.37 桌面牌尺寸统一试验

这版按《牌桌尺寸统一方案》实施，发布为试验版，保留0.5.36基线和同证书回滚包。

## 本次改动

桌面牌河、对手站立手牌、和牌／流局摊牌、自摸牌、副露及拔北牌，统一采用宽0.35的世界尺寸。长和厚继续取雀魂APK的原模型比例。过去的0.29／0.33／0.35角色尺寸入口、自家副露按像素反复缩放和拔北单独缩小已移除。

`TableTileGeometry` 从原模型及描边计算占位、横放间距、牌河行距和叠杠高度。桌面牌的布局父节点保持单位缩放；动画牌读取落地目标的实际尺寸，而不是再次用一个默认宽度生成。

桌面相机、区域锚点及各玩家的朝向沿用原布局。自家副露仍按原来的屏幕右边距／底边距对齐，但只移动，不再缩放。牌组内部间距随实际模型计算，因此一组牌的总跨度会改变。自家二维操作手牌继续使用原正交相机与大小。

这是按原模型和相机统一计算的移植实现。APK的相关Lua仍是加密字节，不宣称已经恢复雀魂全部运行时尺寸源码。
