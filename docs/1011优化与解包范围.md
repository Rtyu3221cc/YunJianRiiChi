## 六项修改

1. **宝牌反光**：使用 APK 的 `dora_shine / dora_shine1` 贴图、`dora_shine / dora_shine_ui` 材质记录与 `mjp_new/effect_dora/dora` 网格、UV 和变换。可见宝牌指示、红五和实际宝牌播放循环反光。指示牌预览由静态缓存改成按帧重绘，盖住的指示牌不亮。
2. **杠牌顺序**：暗杠、明杠搬运完整的新副露组；此前的副露保留。加杠只搬运第四张，原碰的三张保留。提交事件增加公开的副露字符串、类型和序号，轮询后重新绑定对应目标。复用已有原版 Fulu 骨骼帧；杠牌播放适配至 0.45 秒，0.10 秒显示搬运组、0.35 秒交回桌面。吃碰冲击改用 APK `effect_chipeng` 的两组完整粒子模块。视频对照是逐帧分析；这些交接时机属于本项目的录像适配，不是解密出的原脚本时机。
3. **拔北位置**：采用 `scene_mj` 四个 `babei_1..4` 独立锚点和原始 0.0355 单位间距，经牌桌坐标转换。下方玩家从右侧向左累积；右、上、左方分别向下、右、上累积。字面随座位朝向。拔北手部改用原版 Dapai 帧，移除误绑到拔北落地的樱花；参考中的樱花属于点击特效。
4. **计分箭头**：使用 `UI_ScoreChange/container_arrow` 全部 12 个方向的坐标、尺寸、旋转及镜像。相邻用弯箭头，对家用直箭头，三人局映射到下、右、左三个计分框。根据每个和牌结果的公开付款数组识别付款者，避免双响时按总增减误连。计分框原位显示旧排名、变化值与点数；计分结束后再切换新排名。
5. **排名与终局**：使用 APK 的排名字图、`show_num` 原动画缩放曲线、`bg_end0 / bg_end123` 和自家标签。终局先完成单局计分，再进入独立的三／四人排名页，按最终点数和原座位同点顺序排序。保留当前项目的一姬立绘和各玩家头像。省略参考红框内的段位分、货币、PT 和牌谱入口。排名出现时机、页面流程和排版连接代码是客户端适配。
6. **役满火焰与音效**：从 APK 直接恢复 `effect_yiman / effect_yiman2` 的层级、原网格、贴图、材质、六组 ParticleSystem 和 Renderer 全部序列化字段，包括形状、RGB/透明度、大小、速度、序列帧、延迟与循环。没有沿用前版的手工粒子重建。累计／单倍／多倍役满均覆盖。沿用原版 `yakuman` 音效并调整到火焰起始附近；参考混合音轨与该音效的归一化相关度 0.525，匹配位置约 3.765 秒，高于倍满和满贯候选，但不是无背景混音的逐样本相等。

## 不能称为“完好解包全部特效”

| 内容 | 本次实际恢复程度 |
| --- | --- |
| Texture | 本次使用的贴图已解码导出，记录原 bundle、pathID 和 SHA-256。 |
| Material | 原属性、纹理引用及 Shader 渲染状态可读；运行材质适配当前工程。 |
| Shader | 保存原 Android Shader bundle 和编译后属性／混合状态；没有恢复原始 HLSL/ShaderLab 源码。桌面及透明 UI 相机使用既有 Shader 适配器，不能宣称跨 Unity 版本和平台完全相同。 |
| Mesh | 本次用到的网格顶点、UV、索引可恢复并导入。 |
| ParticleSystem | 本次 6 + 6 + 2 组的完整序列化模块已恢复并正确导入；运行时验证模块时长、循环和 Renderer 类型，避免“对象数量正确但字段被忽略”。 |
| Animation | 已导出本次排名使用的 `show_num` 原动画和曲线。已有手部帧来自先前的原版资源导入，不代表 APK 所有动画均已重新完整审计。 |
| 脚本 | 相关 `viewpai / block_babei / viewplayer_me / ui_scorechange / ui_gameend / ui_win` Lua 文件能够原样导出，但内容加密，尚未解密。APK 的 C# 为 IL2CPP，本次没有恢复可编译的原工程源码。 |

因此，当前能恢复并使用本次相关的核心美术和粒子数据，**不能承诺将雀魂全部特效连同 Shader 源码和关联脚本完好还原**。UV 循环、事件交接和界面流程的代码是针对当前客户端的适配，不应称为逐字照搬 APK 脚本。

原始及转换后的资料位于 `unity/Assets/Resources/Majsoul/NativeReview`。`provenance.json` 保留逐项来源和哈希；`Evidence` 的加密脚本只作为来源证据，不在游戏中执行。导入器为 `scripts/import-apk-review-assets.py` 和 `unity/Assets/Editor/ImportNativeReview.cs`，校验器为 `scripts/verify-native-review.py`。
