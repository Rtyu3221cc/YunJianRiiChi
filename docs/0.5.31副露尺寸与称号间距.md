# 0.5.31 副露尺寸与称号间距

按“副露仍过小”和“开局称号离用户名太远”的反馈修正。此次美术素材继续使用已提取的雀魂原图和模型。

- 将 `1012-2/牌桌优化1-原版.jpg` 的实际牌桌区域对齐到 1280×720，再与同一测试局面的修改前后截图比较。
- 自家副露从碰撞框估算改为按 APK 模型及描边的投影轮廓校准。1280×720 下直立方向的副露牌轮廓宽度由 48.36 增至 61.73 像素，约增加 28%；前景手牌高度始终为 101.6 像素。
- 增加右下角的底部留白，接近原图位置。正常横屏保留右下角单排；窄屏空间不足时向上避让，防止副露遮挡手牌或头像。
- 开局“暂无称号”向用户名下移 14 个原版坐标单位；在 1688×780 下约 10 像素。姓名、段位和立绘尺寸不变。
