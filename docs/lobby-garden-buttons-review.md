# 大厅补回按钮预览

按本轮红框补回活动、邮件、排名、公告、问号帮助和寻觅，不扩展未标记的在线系统入口。保留已审阅的玩家名、暂无称号、三场招牌、设置、截图及四个底部菜单。

素材直接提取自 `Majsoul_4.0.16_MC.apk`：`icon_act`、`denglong`、`btn_help`、`btn6`。邮件、排名、公告以 `UI_Lobby/righttop` 的 103 × 165 灯笼、原版间距和标签颜色绘制，字体与原版 Text 指向的 `room-footer`（pathID 3868793191248428975）同属风雨粗毛楷，使用 APK 的简体子集 `brush`，避免“邮”字回退到系统字体，字号 42。活动牌为 145 × 190。寻觅采用 183 × 160 原版比例，并沿用底部菜单已批准的 1.15 倍尺寸。

顶部新增项跟随 `container_top` 入场；寻觅使用已有 `btn_xunmi` 原版上移轨道（延迟 0.2 秒，时长 0.2 秒）。问号排列在设置下方，截图移至下一行。为寻觅预留空间，原有四个底部入口整体左移。

新增按钮有点击反馈；问号显示本地联机说明，其余入口显示暂无内容或暂未开放。没有接入雀魂账号、邮件、排行榜、活动或寻觅业务。

使用 `LobbyMotionPreview` 进行 Unity 渲染截屏和动画导出，包含宽屏、16:9、友人场、安全区及问号说明。此轮不构建 APK、不运行单元测试、不上传 Git，不修改牌桌或打牌代码。待用户审阅。
