## 二、倒牌与拍牌动作

### 1. 自摸（自己自摸.mp4）

总体顺序：「自摸」字样 → 角色切入 → 停顿 → **手牌瞬间放倒** → 手带着和了牌入场拍下 → 牌翻倒 → 和牌特效。

| 时刻 | 相对放倒 L | 事件 |
| --- | --- | --- |
| 0.80s | — | 「自摸」字样出现，手牌仍立着 |
| 1.25–2.30s | — | 角色切入 |
| 2.30–3.12s | — | 约 0.8s 停顿，手牌不动 |
| 3.15→3.18s | **L=0** | 整排手牌在 ≤2 帧内从立起变成正面朝上平放在桌面，没有可见的翻倒补间；和了牌不在这排里 |
| 3.22s | +0.07 | 一只手从屏幕右下角入场，捏着和了牌（牌立着，背面朝镜头） |
| 3.25–3.50s | +0.10→+0.35 | 抬手蓄力：手朝镜头方向抬高，屏幕上明显放大，约 0.25s，缓出 |
| 3.50–3.65s | +0.35→+0.50 | 下砸：快速落到桌面落点，约 0.15s，加速（缓入） |
| 3.65–3.70s | +0.50→+0.55 | 接触，牌立在落点；落地音效应在这里 |
| 3.70–3.80s | +0.55→+0.65 | 手向右下撤出，约 0.1s，缓出 |
| 3.75–3.85s | +0.60→+0.70 | 牌背面朝镜头立着，停约 0.1s |
| 3.85–3.95s | +0.70→+0.80 | 牌以底边为轴向和牌者（镜头）一侧倒下，露出牌面，约 0.1s，加速（重力感） |
| 3.95–4.00s | +0.80→+0.85 | 小幅回弹后静止（约几度） |
| ≈4.80s | +1.65 | 和牌特效在这张牌上爆开 |

落点：在放倒的手牌排右端外侧，间隔约 0.8–1 张牌宽，并比手牌排稍微靠近桌面中心（约半张牌长）。

### 5. 九种九牌（九种九牌.mp4，三麻，本家）

| 时刻 | 事件 |
| --- | --- |
| 0.30→0.33s | 本家手牌从手牌镜头切到桌面上立着（牌面朝本家） |
| 0.33–0.88s | 立着停约 0.55s |
| 0.88→0.92s | 朝本家一侧推倒，正面朝上，约 3 帧 |

| ≈1.0s | 「九種九牌」字样，画面压暗 |

本家亮牌的节奏与荒牌流局一致：切到桌面立着后约 0.55s 才动作。由此推断本家听牌时也应先立着，再推倒（本项目原先在切换的同一帧就推倒，看不到推倒动作）。

### 本项目现状

- 倒牌：`unity/Assets/Scripts/HandRevealMotion.cs` 用 0.58s 曲线，整排以牌底为轴从立起转到平放，含 0.08s 蓄力、0.36s 处冲过 4%、0.44s 回弹。`TableRenderer.SampleDrawReveal` 让所有和牌者/流局各家**同时**倒牌。自己和牌时，手牌相机那排先 0.14s 淡出，再让桌面那排翻倒。
- 自摸拍牌：`TableEffects` 用手部动作数据（`SourcePlaybackContracts.HandAction(...,"Zimo")`），`cue` 为落地音效，`release` 为交接时刻。倒牌在拍牌动作开始的同时开始（`WinActionStarted`），两者重叠。
- 荣和：倒牌在切入之后才开始，没有「宣告时先放倒、特效时再整理」两段。

### 差异与建议（待确认后实施）

1. **放倒改为几乎瞬间完成。** 建议总时长 0.03–0.05s（2–3 帧），线性或缓出，去掉蓄力和过冲。这很可能就是「动作奇怪」的主因：现在是 0.58s 的整排慢倒加回弹，原版是一刀切。
2. **自摸改为先放倒、后拍牌。** 放倒完成后约 0.07s，手才带牌入场，不要和倒牌重叠。拍牌的关键帧按上表：入场 0.03s → 抬手 0.25s（缓出）→ 下砸 0.15s（缓入，如 `t²`）→ 接触 → 撤手 0.10s（缓出）；牌立 0.10s → 向和牌者一侧倒下 0.10s（缓入）→ 回弹 0.05s（超出约 3°）。和牌特效在牌静止后约 0.8s 触发。
3. **荣和拆成两段。** 宣告时立即放倒（正面朝上）；和牌特效触发的那一帧，把手牌换成展示排列并接上荣和牌，用特效遮住切换。
4. **流局依次倒牌。** 左右家 +0.35s，对家 +0.40s，未听牌的本家 +0.55s。未听牌的手牌从「立着、牌面朝持有者」朝前扣倒成背面朝上，不亮牌。各家顺序与间隔可做成参数。
5. **自己和牌时去掉 0.14s 淡出。** 在放倒的同一帧切换手牌相机那排和桌面那排。

- 本家在流局（听牌或未听牌）和九种九牌时，手牌先切到桌面立着，+0.55s（`HandRevealMotion.SelfDelay`）再推倒或扣倒。

### 2026-11-08 自摸拍牌复查（用户指出「竖直砸下、模型穿进牌桌」）

逐帧对照 `自己自摸.mp4` 3.15–4.05s（1/60s）与 0.6.25 的预览录像：

| 项目 | 原版录像 | 0.6.25 | 原因 |
| --- | --- | --- | --- |
| 手的大小 | 接触时手掌约 5 张牌宽 | 约 2.5 张牌宽 | `TsumoHandScale=.48`，只有制作比例的一半 |
| 路线 | 手从右下入场，先抬向镜头（画面里放大到半屏），再划弧落到落点 | 牌只在落点正上方上下移动 | `PositionCarriedTile` 每帧把牌的水平位置钉在落点，抵消了动作本身的弧线 |
| 接触 | 指尖从后方捏住立着的牌顶部，手掌斜向上 | 手平贴桌面，手指穿过立着的牌的下半截 | 动作数据里接触时手几乎贴着桌面（牌点 y≈0.012）；手缩小一半后又被抬高的立牌挡住 |
| 落地后 | 牌背朝镜头立约 0.12s，约 0.10s 倒成正面朝上 | 一致 | — |

动作数据（`tsumo-hand.json`）：牌点从 z=+0.44（靠近和牌者）抬到 y≈0.6，再落到 z≈−0.085，接触在 0.50s 左右。手部网格除 4 个游离顶点外始终在 y≥0，按原比例不会低于桌面。

修正：`TsumoHandScale` 改为 1（制作比例）；`PositionCarriedTile` 不再钉住水平位置，只保证立着的牌不低于桌面。接触关键帧仍映射到落点。
